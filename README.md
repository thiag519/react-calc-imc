# Calculadora de IMC

<h3>
  Este projeto é uma calculadora de Índice de Massa Corporal (IMC) interativa, desenvolvida com React, CSS e TypeScript. 
  Ele permite que os usuários insiram seu peso e altura para calcular automaticamente o IMC, 
  fornecendo também uma análise da faixa correspondente (ex: abaixo do peso, saudável, sobrepeso). 
  O design é funcional e responsivo, garantindo uma experiência intuitiva e agradável   
</h3>



--- 



Projeto em React + typescript fazendo uma cauculadora de IMC.

Projeto desenvolvido durante o curso [B7web](https://b7web.com.br).

 *[Veja o Projeto](https://react-calc-imc-delta.vercel.app/)*
